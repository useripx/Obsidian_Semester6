# 📄 PANDUAN INTEGRASI UPLOAD FILE PHP KE GOOGLE DRIVE (Metode Service Account & Auto-Folder)

## 1. Konsep Dasar Sistem

Sistem ini menggunakan **Google Drive API v3** dipadukan dengan otentikasi **Service Account** (Akun Mesin/Robot). Metode ini dipilih karena:

* Berjalan 100% di latar belakang (tanpa perlu user login akun Google).
* File terkumpul terpusat di satu Google Drive (misal: Drive Ketua/Organisasi).
* Otomatisasi manajemen folder (sistem akan membuatkan sub-folder otomatis berdasarkan ID User agar data rapi dan tidak tercampur).

**Alur Kerja Logika Auto-Folder:**

1. User mengupload file beserta ID mereka (misal: ID 123).
2. Sistem (PHP) mencari folder bernama `folder_user_123` di dalam Folder Utama (Root) KSP/Organisasi.
3. Jika **belum ada**, sistem memerintahkan Google Drive untuk **membuat folder tersebut** dan mengambil ID folder barunya.
4. Jika **sudah ada**, sistem cukup mengambil ID folder tersebut.
5. File yang diupload akan dimasukkan tepat ke dalam folder tersebut.

---

## 2. Persiapan Google Cloud Console

1. Buka [Google Cloud Console](https://console.cloud.google.com/).
2. Buat Project Baru (misal: "Sistem Upload Organisasi").
3. Cari **Google Drive API** di kolom pencarian, lalu klik **Enable** (seperti pada screenshot yang Anda tunjukkan).
4. Masuk ke menu **APIs & Services** > **Credentials**.
5. Klik **Create Credentials** > pilih **Service Account**.
6. Isi nama Service Account (misal: "bot-upload"), lalu selesaikan prosesnya.
7. Di daftar Service Account yang baru terbuat, klik emailnya, masuk ke tab **Keys**.
8. Klik **Add Key** > **Create new key** > Pilih format **JSON**.
9. File `credentials.json` akan terunduh. Simpan file ini ke dalam folder project PHP Anda.

---

## 3. Persiapan Folder di Google Drive (Sebagai Ketua/Manager)

1. Buka Google Drive pribadi Anda.
2. Buat satu folder utama, misalnya bernama `FOLDER_DATA_KSP`.
3. Buka file `credentials.json` menggunakan Notepad/VS Code, cari tulisan `"client_email"`. *Copy* alamat email yang panjang tersebut.
4. Kembali ke Google Drive, klik kanan pada `FOLDER_DATA_KSP` > pilih **Share (Bagikan)**.
5. *Paste* email tadi ke kolom penerima, dan beri akses sebagai **Editor**, lalu klik Send/Bagikan.
6. Buka folder `FOLDER_DATA_KSP` tersebut. Perhatikan URL di browser Anda. *Copy* kode acak di bagian paling belakang URL. Itu adalah **Folder ID Utama** Anda.

---

## 4. Persiapan Project PHP

Buka terminal/CMD di dalam folder project Anda, lalu instal *Google API Client* melalui Composer:

```bash
composer require google/apiclient:^2.15.0

```

---

## 5. Implementasi Kode PHP

Berikut adalah *script* lengkap yang sudah menggabungkan fungsi cek folder, buat folder, dan upload file.

Buat file bernama `upload_cerdas.php`:

```php
<?php
require __DIR__ . '/vendor/autoload.php';

// --- KONFIGURASI AWAL ---
$kredensial = 'credentials.json'; // Path ke file JSON Anda
$folderIdUtama = 'MASUKKAN_ID_FOLDER_UTAMA_DISINI'; // ID dari Langkah 3
// ------------------------

// Simulasi data dari form (misal: Validator memilih ID User 123)
$userId = $_POST['user_id'] ?? '123'; 
$namaFolderUser = 'folder_user_' . $userId;

if ($_SERVER['REQUEST_METHOD'] == 'POST' && isset($_FILES['fileToUpload'])) {
    $file = $_FILES['fileToUpload'];

    try {
        // 1. Inisialisasi Google Client
        $client = new Google_Client();
        $client->setAuthConfig($kredensial);
        $client->addScope(Google\Service\Drive::DRIVE);
        $driveService = new Google\Service\Drive($client);

        $targetFolderId = null;

        // 2. CEK APAKAH FOLDER USER SUDAH ADA
        $query = "name='" . $namaFolderUser . "' and mimeType='application/vnd.google-apps.folder' and '" . $folderIdUtama . "' in parents and trashed=false";
        
        $response = $driveService->files->listFiles(array(
            'q' => $query,
            'spaces' => 'drive',
            'fields' => 'files(id, name)'
        ));

        // 3. LOGIKA PEMBUATAN FOLDER
        if (count($response->files) == 0) {
            // Folder belum ada, mari kita buat!
            $folderMetadata = new Google\Service\Drive\DriveFile(array(
                'name' => $namaFolderUser,
                'parents' => array($folderIdUtama),
                'mimeType' => 'application/vnd.google-apps.folder'
            ));
            $folder = $driveService->files->create($folderMetadata, array('fields' => 'id'));
            $targetFolderId = $folder->id;
            echo "Membuat folder baru untuk User {$userId}... <br>";
        } else {
            // Folder sudah ada, ambil ID-nya
            $targetFolderId = $response->files[0]->id;
            echo "Folder untuk User {$userId} sudah ditemukan. <br>";
        }

        // 4. PROSES UPLOAD FILE KE DALAM FOLDER USER TERSEBUT
        $fileMetadata = new Google\Service\Drive\DriveFile(array(
            'name' => $file['name'],
            'parents' => array($targetFolderId) // Target upload adalah sub-folder
        ));

        $content = file_get_contents($file['tmp_name']);
        
        $uploadedFile = $driveService->files->create($fileMetadata, array(
            'data' => $content,
            'mimeType' => $file['type'],
            'uploadType' => 'multipart',
            'fields' => 'id'
        ));

        echo "<b>Berhasil!</b> File '{$file['name']}' telah diupload ke dalam {$namaFolderUser}.";

    } catch (Exception $e) {
        echo "Terjadi Error: " . $e->getMessage();
    }
}
?>

<!-- Form HTML Sederhana untuk Testing -->
<form action="" method="post" enctype="multipart/form-data">
    <label>ID User / Anggota:</label>
    <input type="text" name="user_id" value="123" required><br><br>
    
    <label>Pilih File Dokumen:</label>
    <input type="file" name="fileToUpload" required><br><br>
    
    <button type="submit">Upload & Rapikan</button>
</form>

```
