## 📂 Struktur Mata Kuliah

Berikut adalah daftar mata kuliah dan materi yang ada dalam repository ini:

- **[01] PKL Sistem Koperasi** 🏦
  - Implementasi sistem informasi untuk koperasi.
- **[02] Pemodelan dan Simulasi** 📈
  - Teori dan praktik pemodelan sistem.
- **[03] Data Mining** 🔍
  - Analisis data, algoritma klasifikasi, clustering, dan implementasi Python.
- **[04] Software Development** 💻
  - Metodologi pengembangan perangkat lunak modern.
- **[05] Bahasa Inggris** 🇬🇧
  - Materi peningkatan kemampuan bahasa Inggris akademik.
- **[06] Pengolahan Citra** 🖼️
  - Algoritma pemrosesan gambar digital.
- **[07] Game Programming Godot** 🎮
  - Pengembangan game menggunakan Godot Engine.
- **[08] Enterprise Architecture** 🏢
  - Perancangan arsitektur sistem informasi skala perusahaan.

## 🚀 Cara Menggunakan
1. Clone repository ini:
   ```bash
   git clone https://github.com/useripx/Obsidian_Semester6.git
   ```
2. Buka folder menggunakan **Obsidian**.
3. Gunakan fitur *Graph View* untuk melihat keterkaitan antar materi.
